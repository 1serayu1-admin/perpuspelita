## 🔄 LANGKAH LOGIN

1. Buka aplikasi Perpuspelita
2. Masukkan **Username** = NIS kamu
3. Masukkan **Password** = NIS + `@pelita`
4. Klik **"Masuk"**
5. Setelah berhasil login, **wajib ganti password**!

---

## ⚠️ PENTING - GANTI PASSWORD!

### Setelah Login Pertama:
1. Klik menu **Profil** (pojok kanan atas)
2. Pilih **"Ganti Password"**
3. Masukkan password baru (minimal 6 karakter)
4. Klik **"Simpan"**

**Kenapa harus ganti?**
- Password default mudah ditebak
- Untuk keamanan akun kamu
- Wajib demi melindungi data pribadi

---

## ❓ LUPA PASSWORD?

### Hubungi Admin:
1. Laporkan ke petugas perpustakaan
2. Sebutkan NIS dan nama lengkap
3. Admin akan reset password ke default (NIS@pelita)
4. Login ulang dan ganti password lagi
